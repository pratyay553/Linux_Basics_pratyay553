1. Creating and Renaming Files/Directories
Task: Create a directory named test_dir using mkdir, create an empty file called example.txt inside test_dir, and rename example.txt to renamed_example.txt using mv.
etrans@Laptop-0234:~$ mkdir test-dir
etrans@Laptop-0234:~$ cd test-dir
etrans@Laptop-0234:~/test-dir$ touch example.txt
etrans@Laptop-0234:~/test-dir$ mv example.txt renamed_example.txt

2. Viewing File Contents
Task: Use cat to display the contents of /etc/passwd, display only the first 5 lines using head, and display only the last 5 lines using tail.
etrans@Laptop-0234:~/test-dir$ cat /etc/passwd
etrans@Laptop-0234:~/test-dir$ head -n 5 /etc/passwd 
etrans@Laptop-0234:~/test-dir$ tail -n 5 /etc/passwd

3. Searching for Patterns
Task: Use grep to find all lines containing the word “root” in /etc/passwd.
etrans@Laptop-0234:~/test-dir$ grep root /etc/passwd

4. Zipping and Unzipping
Task: Compress the test_dir directory into a file named test_dir.zip using zip, and unzip test_dir.zip into a new directory named unzipped_dir.
etrans@Laptop-0234:~$ zip -r test_dir.zip test-dir
etrans@Laptop-0234:~$ unzip test_dir.zip -d unzipped_dir

5. Downloading Files
Task: Use wget to download a file from a URL.
etrans@Laptop-0234:~$ wget https://share.google/WBioVagiyn2Z3q6os

6. Changing Permissions
Task: Create a file named secure.txt and change its permissions to read-only for everyone using chmod.
etrans@Laptop-0234:~/test-dir$ chmod 444 secure.txt

7. Working with Environment Variables
Task: Use export to set a new environment variable called MY_VAR with the value “Hello, Linux!”.
etrans@Laptop-0234:~/test-dir$ export MY_VAR="Hello, Linux!"
etrans@Laptop-0234:~/test-dir$ echo $MY_VAR
Hello, Linux!
